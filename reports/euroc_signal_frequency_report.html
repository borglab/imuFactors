How Ground Truth Was Interpolated

The merge code reads the original EuRoC ground-truth stream and IMU stream separately, then emits one output row for each IMU timestamp. For each IMU time t, it advances to the neighboring ground-truth samples t0 and t1, computes alpha = (t - t0) / (t1 - t0), and interpolates the navigation state with GTSAM's NavState Lie-group operations: xi = X0.logmap(X1), then X = X0.expmap(alpha * xi).

The interpolated NavState supplies orientation, position, and velocity. Gyro and accelerometer biases are interpolated componentwise with ordinary linear interpolation: (1 - alpha) * bias0 + alpha * bias1. If an IMU timestamp is outside the ground-truth time span, the code clamps to the first or last ground-truth sample.
